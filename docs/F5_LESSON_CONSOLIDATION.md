# F5 lesson consolidation

The learner-facing module now contains:

- F5.1 Keyboard Basics: basic keyboard input and useful keyboard operations.
- F5.2 Understanding Coordinates and the Origin: original origin instructions and illustration, coordinate axes, and positive/negative directions.
- F5.3 Specifying Coordinates: mouse and keyboard coordinate entry.

The course contains 60 active lessons. Storage IDs remain F5.1, F5.4 and F5.6; displayId provides the requested sequential labels. Coordinate Input Practice (storage ID F5.8) has been removed from the active curriculum. Historical records and original tutorial assets are retained.
