# Legacy course retirement

## Scope

User explicitly authorized removing legacy employee courses as well as unused lessons/assets. The three paid plans remain. Employee course selection no longer synthesizes 3D Modeling or 2D Detailing; course loading excludes those retired course types, including on refresh. Their hard-coded lesson routes were removed. Stored entitlements, historical completion records and backend data were not modified.

## Retained shared resources

The 3D interface, toolbar and basic-operation components, video players and tutorial data remain dependencies of current Foundations/Professional renderers. The 2D CourseLesson stylesheet is shared with DynamicFoundationsLesson. The assessment illustration and images directly used by current lessons remain.

## Removed files

323 files; 62,312,864 bytes: 39 lesson components, one obsolete audit script, and 283 assets.

## Validation

Final TypeScript and production build passed after all deletions. Vite reports a non-failing bundle-size warning. Five targeted tests passed (course loading/refresh filtering and four canonical Foundations routing tests); routing tests required a 20-second test timeout for initial lazy loading. Retained course hashes match the pre-cleanup baseline. Earlier Professional curriculum parity failure is outside this cleanup.
